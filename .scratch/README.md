# Local issue tracker

Issues and specs for this repository live as markdown files here, one directory
per feature:

```
.scratch/<feature-slug>/
├── spec.md
└── issues/
    ├── 01-<slug>.md
    └── 02-<slug>.md
```

The convention is described in
[`docs/agents/issue-tracker.md`](../docs/agents/issue-tracker.md).

The course's own work backlog lives in [`tasks/`](../tasks/) — that is the
authoritative list of what still has to be built.
